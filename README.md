# cbs RADAR – 30 s motion video

▶ **Watch:** https://markusjordan1988.github.io/cbs-radar-video/

- `index.html` / `cbs-radar-30s.html` – self-contained HTML video (built from `src/*.html` via `cat src/*.html > cbs-radar-30s.html`)
- `cbs-radar-30s.mp4` – 1080p/30fps render

Controls: Space play/pause · R restart · ←/→ seek · V voice-over · L loop · F fullscreen.
URL params: `?t=18` (jump), `clean=1` (hide UI), `loop=1`, `vo=1`.
